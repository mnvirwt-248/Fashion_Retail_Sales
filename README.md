# Fashion Retail Sales Analysis

## Project Overview

This project focuses on analyzing a Fashion Retail Sales dataset using Python. The main objective was to understand customer purchasing behavior, sales performance, product trends, and payment preferences through data analysis and visualization.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Project Tasks Performed

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Sales Trend Analysis
* Customer Rating Analysis
* Product Performance Analysis
* Payment Method Analysis
* Data Visualization

## Key Insights

* Identified top-selling products.
* Analyzed customer ratings and purchasing patterns.
* Examined different payment methods used by customers.
* Studied purchase amount trends and sales performance.
* Generated visualizations to support business insights.

## Files Included

* Fashion_Retail_Sales.ipynb
* Fashion Retail Sales Dataset.csv
* Fashion Retail Sales Project Report.pdf
